# 🚀 InfraSight

### Advanced Network Intelligence System

InfraSight is a real-time network monitoring platform designed to detect devices, analyze traffic, and identify potential threats within local networks using OSINT-based intelligence techniques.

---

## 🧠 Overview

InfraSight provides full visibility over your network:

* Identifies all connected devices
* Detects unauthorized access
* Analyzes traffic in real time
* Generates behavior-based alerts

Built for modern environments where security and control are critical.

---

## 🔥 Key Features

* 🔍 Network Discovery (ARP Scanning)
* 🧠 Device Fingerprinting (MAC + Vendor Identification)
* 🚨 Intrusion Detection
* 📡 Real-time Traffic Sniffing
* 📊 Behavioral Analysis
* 🗃️ Historical Device Tracking
* ⚠️ Intelligent Alerts

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/AlanTinajero/InfraSight.git
cd InfraSight
```

Create a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run

```bash
sudo streamlit run app.py
```

Then open:

http://localhost:8501

## 📡 How It Works

InfraSight operates through multiple layers:

1. **ARP Scanning**
   Discovers active devices on the network

2. **Fingerprinting**
   Identifies device manufacturers via MAC addresses

3. **Traffic Analysis**
   Captures packets in real time

4. **Anomaly Detection**
   Flags unknown or new devices
